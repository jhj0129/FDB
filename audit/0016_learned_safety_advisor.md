# 감사 0016 학습형 안전 조언기 추가

- 변경: Panda hand 자세와 그리퍼 상태로 테이블 접촉 가능성을 사전 판별하는 신경망
  앙상블을 추가했다.
- 실패 증거: 확률 0.5만 사용한 최초 시험은 위험 표본 1개를 안전으로 오판했다.
- 교정: 서로 다른 bootstrap 모델의 불일치를 별도 gate로 추가했다.
- 최종 정책: 독립 시험의 위험 표본 11개 중 통과 0개, 안전 표본 과잉 거부 3개.
- 권한 경계: 학습망은 조기 거부만 할 수 있고 안전을 최종 승인할 수 없다. 허용 후보도
  MuJoCo 접촉 0과 관통 0 하드 gate를 통과해야 한다.
- 승격 상태: 한 로봇과 한 테이블 범위이므로 validated가 아닌 candidate로 기록한다.
