# 감사 0017 다중 로봇·다중 과제 전환

- 사용자 피드백: 한 과제의 완성도만 높이지 말고 휴머노이드 챌린지처럼 여러 로봇과
  다양한 과제를 경험하도록 방향을 넓힌다.
- 변경: 네 오픈소스 휴머노이드와 다섯 과제를 같은 실행기로 평가했다.
- 점수 원칙: 구조상 불가능한 과제는 실패가 아니라 `해당 없음`으로 기록한다.
- 실패 보존: T1 외란, OP3 연속 외란, Berkeley 기본 서기 실패를 삭제하거나 성공으로
  포장하지 않고 다음 학습 우선순위로 남긴다.
- 승격 경계: 이 실행기는 공통 기준선 후보이며 보행 또는 휴머노이드 제어 skill로
  승격하지 않는다.
