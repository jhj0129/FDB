# 감사 0021 — 능력 상태를 증거에서 파생

## 문제

`state/capability_profile.json`은 최신 실험 결과인 25/36을 기록했지만
`cognitive_curriculum.py`는 과거 점수 18/36을 코드에 고정하고 있었다. 명령을 다시
실행하면 검증된 최신 상태가 과거 값으로 되돌아갈 수 있었다.

## 변경

- 현재 점수와 근거 파일을 `experiments/capability_evidence.json`에 분리했다.
- 생성기는 증거 필드, 점수 범위, 중복 능력, 근거 파일 존재 여부를 검증하고 합계만
  계산한다.
- 현재 상태에 출처와 증거 개정 시각을 기록한다.
- 이미 해결된 다중 형상 일반화 질문을 `current_goal.json`에서 제거하고 지속 장면의
  물체 정체성 문제로 교체했다.

## 판정

생성 전후 운영 점수는 25/36이며 동역학 보행 점수는 4/4로 유지된다. 증거 파일을
바꾸지 않는 한 실행 코드만으로 점수가 후퇴하지 않는다.
