# CMU 사람 동작 자료

- 출처: [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/)
- 피험자/동작: subject 69, trial 01, walk forward, 120 Hz
- 원본 파일: `69.asf`, `69_01.amc`
- FDB 사용 구간: AMC 프레임 61~203(143프레임, 약 1.19초 보행 주기)

CMU 데이터베이스는 모든 용도에 무료로 사용할 수 있다고 명시하며, 데이터 자체의 재판매는
허용하지 않는다. 이 저장소는 연구 실험의 재현을 위해 원본과 출처를 함께 보관한다.
CMU의 안내에 따라 발가락/손 관절은 노이즈가 있을 수 있으므로 현재 제어 입력에서는 제외했다.

Acknowledgment: The data used in this project was obtained from mocap.cs.cmu.edu.
