# 실험 0014 학습형 밀기 세계모델

- 상태: 제한된 planar push 범위에서 후보 기술
- 데이터: MuJoCo 독립 rollout 3,900개
- 분할: 학습 2,400개, 검증 500개, 시험 500개, 분포 밖 시험 500개
- 모델: 멤버당 4,930개 파라미터를 가진 MLP 5개 앙상블
- 실행 환경: CPU PyTorch 2.14.0과 MuJoCo 3.13.0 분리 환경

시험 세트 평균 위치 오차는 10.72mm, 95백분위 오차는 24.49mm였고 성공 판정
정확도는 99.4%였다. 단순 평균 위치 기준선의 평균 위치 오차 1.233m보다 크게
개선됐다. 앙상블 불확실성 기준은 검증 세트의 95백분위인 16.31mm로 고정했다.

분포 밖 세트에서는 평균 오차가 19.82mm로 증가했으며 58.6%를 물리 시뮬레이션
fallback 대상으로 표시했다. 하이브리드 계획기는 학습 분포 경계 또는 불확실성
기준을 넘으면 신경망 결과를 사용하지 않는다. 신경망으로 선택한 후보도 실제
MuJoCo 실행으로 다시 검증한다.

최종 시연에서 신경망 예측과 실제 최종 위치의 차이는 3.32mm였다. 이 결과는 한 개의
planar push 환경에 한정되며 Panda 접촉 동역학이나 실제 로봇 일반화를 의미하지 않는다.
