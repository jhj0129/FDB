# 실험 0016 학습형 테이블 충돌 상식

- 상태: 시뮬레이션 후보
- 목적: Panda 손과 그리퍼를 너무 낮게 내려 테이블을 관통시키는 자세를 실행 전에 거부한다.
- 데이터: MuJoCo에서 무작위 hand 자세 180개를 각각 1,000 step 실행
- 라벨: 로봇과 테이블의 접촉이 한 step도 없을 때만 안전
- 구성: 4개 자세 특성을 입력받는 1,249 parameter MLP 5개 앙상블

데이터에는 안전 117개와 충돌 63개가 포함된다. 학습망은 안전 확률뿐 아니라 다섯
모델 사이의 불일치도 계산한다. 독립 시험 32개에서 확률만 사용할 경우 위험 자세
1개를 통과시키는 실패가 있었다. 이 결과를 숨기지 않고, 앙상블 불확실성 gate와 학습
분포 gate를 함께 적용했다. 최종 보수 정책은 위험 11개를 모두 거부해 false-safe 0,
safe precision 1.0을 기록했으며, 안전 자세 3개도 함께 거부해 전체 정확도는 90.625%다.
안전 영역에서의 과잉 거부는 물리검증 비용 증가로 처리한다.

과거 관통 자세인 파지 hand z=375mm와 배치 z=385mm는 학습 gate에서 거부된다.
교정 자세인 파지 z=435mm와 배치 z=465mm는 통과하지만, 이것은 최종 안전 승인이
아니다. 허용된 모든 자세는 기존 MuJoCo 접촉·관통 하드 gate를 반드시 다시 통과해야
한다. 신경망은 조기 거부 도구이며 하드 gate를 대체하거나 우회할 권한이 없다.

근거는 `experiments/0016_v5_safety_classifier.metrics.json`,
`models/v5/panda_table_safety.pt`, `models/v5/panda_table_safety.npz`,
`tests/test_v5_safety_advisor.py`에 보존한다.
