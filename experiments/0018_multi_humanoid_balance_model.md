# 실험 0018 다중 휴머노이드 단기 낙상 예측

- 로봇: G1, Booster T1, Robotis OP3, Berkeley Humanoid
- 데이터: 로봇당 48회, 총 192회
- 입력: 질량·높이·축 수·body 수, 외란 크기·방향·시간, 외란 전 자세와 무릎 동작
- 모델: 1,505 parameter MLP 5개 앙상블
- 출력: 다음 1초 안에 직립을 유지할 확률과 모델 불일치

첫 자료는 관찰 시간이 너무 길어 T1 48회 중 47회, Berkeley 48회 전부가 낙상했다.
이 자료로 만든 모델은 테스트 안정 recall이 7.7%에 불과해 거의 모든 후보를 거부했다.
예측 창을 다음 행동 선택에 맞는 1초로 줄이고 외란 범위를 체중의 0~45%로 넓혔다.
재생성 자료는 안정 95, 낙상 97로 개선됐다.

최종 독립 시험 32회에서 낙상을 안정으로 통과시킨 오류는 0, 안정 precision은 1.0,
안정 recall은 41.2%, 전체 정확도는 68.8%다. 즉 안전하다고 강하게 합의한 후보는
정확했지만 실제 안정 후보 10개를 과잉 거부했다. 이 모델은 물리 rollout 수를 일부
줄이는 사전 screen 후보일 뿐이며, 허용 결과도 최종 MuJoCo 검증을 면제하지 않는다.

모든 로봇 종류가 학습 자료에 포함되어 있으므로 처음 보는 휴머노이드 일반화는 아직
증명되지 않았다. 다음 gate는 로봇 하나를 통째로 제외한 leave-one-robot-out 평가와
균형 recovery 행동 학습이다.
