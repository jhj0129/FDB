# 실험 0019 다중 물체 분류 앙상블

- 입력: RGB 세 값과 물체 반쪽 크기 x/y/z
- 클래스: `red_small`, `green_wide`, `blue_tall`
- 자료: 색 잡음과 치수 잡음을 더한 합성 관측 720개
- 학습/독립 시험: 576/144
- 모델: 6-16-16-3 MLP 5개 앙상블
- 독립 시험 정확도: 100%
- 최소 앙상블 신뢰도: 0.9981
- portable 추론: `models/v5/object_sort_ensemble.npz`

세 클래스가 색으로 크게 분리된 제한된 후보 실험이므로 일반 물체 인식 성능으로 해석하면
안 된다. 이후에는 카메라 영상, 조명 변화, 가림, 비슷한 색과 처음 보는 물체를 포함해야
한다. 분류기가 높은 신뢰도를 내더라도 충돌과 안전 높이는 MuJoCo 하드 게이트로 다시
검사한다. 최종 다중 물체 실행은 PyTorch 없이 NumPy portable 앙상블을 직접 호출한다.
학습 prototype에서 정규화 거리 4.5를 넘거나 앙상블 신뢰도가 0.90 미만이면 세 클래스 중
하나를 억지로 고르지 않고 `unknown`으로 거부한다. 노랑·가로형·비정상 크기를 결합한
시험 물체가 이 gate에서 거부되는 것을 회귀검사로 고정했다.
