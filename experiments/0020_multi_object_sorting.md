# 실험 0020 Panda 다중 물체 분류·배치

한 장면에 빨강 소형 정육면체, 초록 가로형 직육면체, 파랑 세로형 직육면체를 놓고
각각 분류한 뒤 색상 구역에 순서대로 집어 옮겼다.

- 분류 정확도: 3/3, 100%
- 물리 배치 성공: 3/3, 100%
- 최종 XY 오차: 2.25mm, 2.53mm, 3.15mm
- 비의도 로봇-테이블 접촉: 0 step
- 최대 테이블 관통: 0mm
- 최소 hand-테이블 여유: 116.2mm
- 영상: `artifacts/fdb_multi_object_sorting.mp4`

모든 횡이동은 물체를 먼저 70mm 이상 들어 올린 뒤 수행한다. 물체가 지지 높이에 도달한
뒤에만 그리퍼를 열며, 열린 뒤 후퇴한다. 이번 장면은 고정된 세 물체의 기하학적 분류와
순차 조작 검증이다. 카메라 기반 인식과 무작위 초기 배치는 다음 gate다.
