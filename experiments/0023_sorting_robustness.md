# 실험 0023 다중 물체 위치 변화 강건성

세 물체의 source와 색상별 target 위치를 작업영역 안에서 두 세트 바꾸고 nominal을 포함한
세 장면을 다시 실행했다.

- 장면: 3
- 물체 조작: 9회
- 분류·배치 성공: 9/9
- 모든 장면 로봇-테이블 접촉: 0
- 모든 장면 최대 테이블 관통: 0mm
- 모든 장면 안전 hard gate: 통과

이는 고정 좌표 하나를 외운 궤적이 아니라 각 물체의 관측 위치로 IK 목표를 다시 만든다는
증거다. 다만 배치와 크기가 알려진 작은 범위이고 물체끼리 가리지 않는다. 다음 강건성
gate는 무작위 표본, 카메라 관측 오차, 가림, 비슷한 색 및 일부 실패 후 재계획이다.
