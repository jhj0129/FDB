# 실험 0030 — 명령·카메라·신경망·물리 삽입 통합

## 실행 체인

`네모를 네모칸에 넣어` → 한국어 목표 구조화 → 상단 카메라 촬영 → 색 기반 관심영역
추출 → CNN 물체/수용구/fit/회전 추론 → 불일치 안전 거부 → Panda grasp → 손목 회전
→ 수용구 삽입 → 접촉을 통한 미세 정렬 → release → 결과 확인.

인식 단계는 MuJoCo 내부의 물체 `shape` 정답을 읽지 않는다. 작업 물체와 수용구만 보이는
고정 카메라의 RGB 픽셀에서 윤곽을 얻고, CNN 입력으로 정규화한다. 영상 좌표와 월드 좌표의
반사 관계만 고정 카메라 외부 파라미터로 보정한다.

## 기본 장면 결과

- 물체 24°, 수용구 -12°.
- CNN 계획 회전 -34.19°.
- 최종 중심 오차 1.28mm.
- 최종 방향 오차 3.24°.
- 로봇-탁자 충돌 0회.
- release 성공, 삽입 성공.

## 처음 보인 회전 배치

기본 장면 외 세 배치 `(-31°, 17°)`, `(8°, -28°)`, `(39°, 2°)`를 시험해 4/4를
통과했다. 최대 최종 중심 오차는 7.76mm, 최대 최종 방향 오차는 3.24°다.
