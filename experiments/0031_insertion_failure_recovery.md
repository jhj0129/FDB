# 0031 삽입 실패 감지와 재시도 복구

## 목적

첫 시각 판단이 틀렸을 때도 실패를 성공으로 기록하지 않고, 새 상태의 MuJoCo 후보 실행으로
손목 회전 보정을 찾은 뒤 실제 과제를 다시 수행한다.

## 실험

- 카메라 추정 회전에 의도적으로 40도를 더해 첫 삽입을 실패시켰다.
- 0, -10, +10, -20, +20도 보정을 서로 독립적인 초기 상태에서 시험했다.
- 성공 판정은 해제 여부, 중심·높이·회전 오차와 로봇-테이블 충돌 0회를 모두 요구했다.

## 결과

- 첫 시도: 실패
- 선택한 추가 보정: -20도
- 복구 시도: 성공
- 최종 중심 오차: 3.14mm
- 최종 회전 오차: 2.50도
- 비의도 로봇-테이블 접촉: 0회

이는 현재 장면의 제한된 회전 오차를 후보 시뮬레이션으로 복구한 결과다. 아직 실제 접촉력
센서 기반 탐색이나 임의 형상에 대한 일반 복구 정책은 아니다.
