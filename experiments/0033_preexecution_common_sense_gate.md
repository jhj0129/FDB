# 0033 실행 전 조작 상식 안전 게이트

그리퍼가 바닥에 파고든 뒤 접촉 횟수만 세는 방식은 충분하지 않다. 모든 Cartesian 경유점을
실행하기 전에 검사해 손 안전 외피와 운반 물체의 최저점이 작업대 아래로 내려가는 계획을
거부하도록 했다. 물체가 표면에 닿는 것은 이름이 `insert`인 최종 삽입 단계에서만 허용한다.

정상 정사각형 삽입 계획은 통과하며 기존 물리 실행에서도 로봇-테이블 접촉 0회를 유지한다.
손 중심이 낮은 계획과 물체를 바닥에 끌고 가는 계획은 IK 계산과 시뮬레이션 전에 예외로
중단된다. 이는 학습된 상식 전체가 아니라, 반복해서는 안 되는 위험 행동을 명시적 불변식으로
고정한 안전층이다.
