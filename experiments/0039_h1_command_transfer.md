# 0039 — H1 속도·측면·회전·정지 명령 전이

사람 보행률 설정을 유지한 채 공식 H1 정책에 15초 명령을 주어 다음 gate를 탐색했다.

| 명령 | 직립 | 연속 교대 걸음 | 결과 |
|---|---:|---:|---|
| 정지 `(0, 0, 0)` | 예 | 3 | 실패: 1.18m 표류 |
| 느린 전진 `(0.3, 0, 0)` | 예 | 30 | 성공 |
| 왼쪽 측면 `(0, 0.3, 0)` | 예 | 29 | 성공 |
| 좌회전 `(0.4, 0, 0.4)` | 예 | 15 | 부분 성공: 여러 바퀴 과회전 |
| 우회전 `(0.4, 0, -0.4)` | 예 | 14 | 부분 성공: 여러 바퀴 과회전 |

위상 입력을 네 지점에 고정하는 정지 후보도 시험했지만 세 지점은 낙상했고, 직립한
한 지점도 13.64m 표류해 채택하지 않았다. 따라서 현재 정책은 전진·측면 연속 보행은
가능하지만 “정지”와 목표 각도 회전은 수행하지 못한다.

다음 구현은 보행 정책 하나에 모든 상태를 억지로 맡기지 않고, 감속 구간→양발 접촉
확인→검증된 정적 균형 제어기로 넘기는 상태 전환과 회전 각도 폐루프를 추가해야 한다.
