# 로봇 외형·시각 무결성 원칙

로봇 과제를 설계하고 성공을 판정할 때 다음 원칙을 기본값으로 적용한다.

1. 사용자가 명시적으로 요청하지 않는 한 원본 로봇의 보이는 외형에 패드, 플레이트, 브래킷 등의 부품을 추가하지 않는다.
2. 충돌 계산을 위한 단순 형상은 원본 외형 내부에만 배치하고 렌더링하지 않는다.
3. 충돌 프록시 접촉만으로 성공을 인정하지 않는다. 렌더링되는 원본 메시와 물체의 표면 거리, 작업대 여유, 실제 영상을 함께 확인한다.
4. 로봇의 최소·최대 파지 폭과 가동 범위에 맞지 않는 물체라면 로봇 외형을 임의로 개조하지 않고, 먼저 과제나 물체가 해당 도구에 적합한지 판단한다.
5. 최종 영상에서 사람이 보기에 물체가 떠 있거나, 손가락이 표면을 뚫거나, 부품이 공중에 분리되어 보이면 수치상 성공이어도 실패로 처리한다.
6. 외형 변경이 반드시 필요하다면 변경 이유와 대안을 먼저 사용자에게 설명하고 승인을 받은 뒤 적용한다.

이 원칙은 새로운 로봇 모델과 그리퍼를 적용할 때도 동일하게 사용한다.
